# Démarrage rapide

1. Ouvrir Windsurf, Cursor, Antigravity ou un agent ; donner accès au projet local ou au ZIP et à l'URL GitHub de référence, et à la DRI ZIP (ou dossier explicitement choisi).
2. Placer ce dossier dans les ressources accessibles. Ne pas remplacer un dossier local par GitHub. Indiquer si possible branche/commit, source de travail et une zone séparée autorisée pour le suivi et les maquettes fictives.
3. Copier **intégralement** [MASTER_ORCHESTRATION_PROMPT.md](MASTER_ORCHESTRATION_PROMPT.md) dans l'agent ; il trouve et lit lui-même les sous-prompts.
4. Répondre aux seules portes nécessaires : source si ambiguë, lot/rôles, direction artistique, partage Stitch/Figma et validation. L'agent enchaîne les tâches sans vous demander chaque prompt.
5. S'il n'a pas accès à Figma/Stitch ou à une zone d'écriture, suivre la demande d'accès ou les instructions manuelles : un texte ou un faux écran ne remplace pas un vrai prototype testé. L'intégration de code exige une autorisation distincte.

Le ZIP contient une copie du PDF V3 et les sources historiques utilisées. Les ressources réelles du projet et la DRI sont à fournir à l'agent séparément. Aucune authentification GitHub ni donnée réelle n'est incluse.
