## Trois choses à savoir avant de commencer

1. **Aucun projet n'est choisi.** L'idée « radar de liquidité » est une proposition de l'assistant précédent, pas une décision.
2. **Le guide PDF d'Epi'AI n'est pas un document des organisateurs.** Il le dit lui-même. Le formulaire officiel prime.
3. **Les compétences de trois des quatre membres ne sont pas documentées.** Il faut les recueillir avant d'évaluer la faisabilité d'une idée.

## Ce qui n'est pas dans ce dépôt

Le dépôt est public. N'y figurent pas : le PDF du guide, les captures d'écran, les noms complets et les coordonnées des coéquipiers. Stane-Junior les détient et peut les fournir directement.

## Conventions

- Chaque information porte un statut : fait confirmé, décision validée, proposition, hypothèse, question ouverte, réalisé, restant, non documenté.
- « Non documenté » signifie que l'information est absente de la conversation et des documents. Rien n'a été comblé par supposition.
- Les coéquipiers sont désignés par leurs initiales.
