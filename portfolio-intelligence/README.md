## Règles d'usage (à respecter dans toutes les réponses futures)

1. Deux classements distincts, jamais mélangés : **A** (portfolio présentable) et **B** (expérience élargie).
2. Un projet client ou collectif est toujours présenté avec son contexte et le rôle exact.
3. Aucun score, classement ou modèle entraîné n'est cité sans preuve dans les sources.
4. Ce qui est « prévu » ou « documenté » n'est jamais présenté comme « livré ».
5. Les niveaux de [04](04_CARTOGRAPHIE_COMPETENCES.md) priment sur toute formulation flatteuse.
